
# Рефакторинг интернет-магазина на React

## Описание проекта:
Рефакторинг кода интернет-магазина на React с устранением антипаттернов и улучшением архитектуры.

## Использованные технологии и навыки:
- **React 18**: функциональные компоненты, хуки
- **Redux Toolkit**: управление состоянием
- **React Hooks**: `useState`, `useEffect`, `useMemo`
- **React Context API**: глобальное состояние
- **Container/Presentational компоненты**: разделение логики и представления
- **Оптимизация производительности**: `React.memo`, `useMemo`, `useCallback`
- **Тестирование**: ESLint, Prettier, Jest, React Testing Library

## Архитектурные решения:
- **Слоистая архитектура**: Presentation, Business Logic, Data Layer
- **Принципы**: SOLID, DRY, KISS, YAGNI
- **Модульная архитектура**: разделение кода на модули

## Оптимизация:
- **Селекторы**: мемоизация производных данных
- **Производительность**: оптимизация ререндеров
- **Code Splitting**: динамические импорты
- **API интеграция**: REST API, кеширование

## Решенные проблемы:
1. Устранение God Component
2. Оптимизация Redux Store
3. Внедрение мемоизированных селекторов
4. Оптимизация ререндеров
5. Упрощение структуры проекта

## Запуск проекта:
```bash
git clone https://github.com/bellatrisa1/online-shop-test-task.git
npm install
npm run dev
```
