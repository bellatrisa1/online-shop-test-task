# Рефакторинг интернет-магазина

## Внесенные изменения:

### 1. Структура проекта
- Разделение монолитного App.jsx на компоненты
- Создание модульной структуры папок
- Выделение логики в хуки

### 2. Исправление Redux антипаттернов
- Удалены дублирующиеся состояния (cartCount, totalPrice, cartTotalAmount и т.д.)
- Созданы мемоизированные селекторы для производных данных
- Исправлено использование строковых actions на импортируемые экшены
- Упрощена логика редюсера

### 3. Разделение ответственности
- Вынесена логика фильтрации в кастомный хук `useProductFiltering`
- Созданы презентационные компоненты (ProductCard, CartItem)
- Разделены компоненты на умные и глупые

### 4. Устранение дублирования кода
- Убрано повторяющееся вычисление total в редюсере
- Вынесены константы и утилиты
- Упрощена логика работы с корзиной

### 5. Улучшение поддерживаемости
- Добавлены правильные экспорты через index.js файлы
- Создана четкая структура зависимостей
- Улучшена читаемость кода

### 6. Оптимизация производительности
- Добавлен useMemo для фильтрации продуктов
- Мемоизированные селекторы предотвращают лишние пересчеты
- Устранены ненужные ререндеры

## Решенные проблемы:

1. **Антипаттерн "God Component"** - разделен монолитный компонент
2. **Прямой dispatch строковых экшенов** - заменен на импортируемые
3. **Дублирование бизнес-логики** - вынесено в селекторы и хуки
4. **Избыточные состояния в Redux** - удалены дублирующие поля
5. **Смешивание логики и представления** - разделение на компоненты
6. **Отсутствие структуры проекта** - создана модульная архитектура
7. **Неправильное использование useEffect** - исправлены зависимости
